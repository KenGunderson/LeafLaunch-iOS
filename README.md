# Grimoire Template 🚀

Welcome to **Grimoire**—your magical starting point for SwiftUI apps! Before you unleash your own spellbook of features, work through this quick‑start checklist to replace all placeholders and get up and running in no time.

> 🔍 **Pro Tip:** Search the entire codebase for `Grimoire` (all‑lowercase, all‑caps, and CamelCase) and replace it with **your** app’s name wherever it makes sense.

---

## 🛠 Project Setup
- [ ] **Project Name**  
  – Rename the Xcode project, targets & schemes from `Grimoire` to your app’s name  
- [ ] **Bundle Identifiers & Targets**  
  – Update all bundle IDs, app extensions, and target names  
- [ ] **Info.plist & Resource Paths**  
  – Verify that all `.plist` files (including nested ones) are in the correct resource bundles  
  – Update any hard‑coded paths  

## 🔐 Permissions & Privacy
- [ ] **Required Permissions**  
  – Camera, Location, Photo Library, etc.  
- [ ] **Privacy Strings**  
  – Update `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`, etc. in your Info.plist  

## 🔗 Deep Links & Firebase
- [ ] **Firebase Configuration**  
  – Replace `GoogleService-Info.plist` with your project’s file  
  – Update any `FirebaseApp.configure()` calls if needed  
- [ ] **Deep Link Schemes & Domains**  
  – Set up your URL schemes, Associated Domains, and Universal Links  

## 🧭 Navigation & Tabs
- [ ] **App Navigation**  
  – Review `NavigationStack`, `TabView` or custom router  
- [ ] **Tab Bar**  
  - [ ] **Items & Labels** (titles, badges)  
  - [ ] **Icons** (SF Symbols or custom assets)  
  - [ ] **ViewModel & Screen Naming**  
  - [ ] **File Structure & DI Registration**

## 📐 Constants & Configuration
- [ ] **App‑Wide Constants**  
  – API endpoints, feature flags, theme tokens  
- [ ] **Environment / Build Config**  
  – `.xcconfig` or `.env` files for staging/production values  

## ✨ App Content & Releases
- [ ] **What’s New Screen**  
  – Update placeholder release notes and feature highlights  
- [ ] **Launch Screens & Assets**  
  – Verify your Launch Storyboard / SwiftUI launch view and app icons  

## ✅ Final Sweep
- [ ] **Search & Replace**  
  – Double‑check that `Grimoire` (and variations) are all replaced  
- [ ] **Remove Sample Code**  
  – Clean up any demo views, comments, or dummy data  
- [ ] **Smoke Test**  
  – Build, run on device/simulator, and verify core flows
